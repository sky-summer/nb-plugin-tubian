# nonebot-plugin-tubian

《星际争霸》每周突变查询插件。根据「突变列表数据.xlsx」与当前时间自动选中本周突变并返回。

## 功能

| 指令 | 说明 |
| --- | --- |
| `突变` / `本周突变` / `tb` | 查询本周突变（按当前时间自动选中） |
| `下周突变` / `tbx` | 查询下周突变 |
| `突变 <序号>` | 按轮换序号查询，如 `突变 128` |
| `突变查询 <名称>` | 按突变名称 / 地图名称搜索，如 `突变查询 恐惧神庙` |
| `因子查询 <名称>` / `因子 <名称>` | 查询单个因子的效果，如 `因子查询 短视症` |
| `随机残酷 [1~6]` / `残酷+<N>` / `sjck` | 随机残酷+开局：因子组合 + 地图 + 埃蒙部队 |
| `订阅突变` / `退订突变` | 订阅 / 取消每周一 08:00 的本周突变推送 |（不可用）
| `测试推送` | 立即执行一次推送任务（测试用，与定时任务同路径） |
| `帮助` / `help` | 查看全部功能（`突变 帮助` 亦可） |

返回内容包含突变名称、地图（附地图图片）、开放日期、剩余时间、突变因子（附因子图标）等信息。

## 选中规则

- 每期突变自其「日期」（周一）起开放 7 天，按周轮换；
- 按当前日期落在哪一期的时间窗口内选中「本周突变」；
- 数据共 184 期，构成一轮完整循环，超出数据覆盖范围时按整轮折算。

## 随机残酷

残酷+ 在每周突变之上叠加额外因子，因子按强度赋 1～10 分，各难度档位对
当期因子的点数总和与因子个数做筛选：

| 难度 | 点数总和 | 因子个数 |
| --- | --- | --- |
| 残酷+1 | 4～6 | 2～3 |
| 残酷+2 | 7～8 | 2～3 |
| 残酷+3 | 9～10 | 2～3 |
| 残酷+4 | 11～12 | 2～3 |
| 残酷+5 | 15～16 | 2～4 |
| 残酷+6 | 19～20 | 2～4 |

「随机残酷」在 1～6 档中随机选档并生成因子组合；「随机残酷 3」指定档位
（`残酷+3` 亦可）。因子个数先在允许范围内均匀取值，再在该个数的全部合法
组合中均匀抽取，避免组合数量占优的大个数（如 4 因子）几乎垄断抽取结果。
节日限定因子（不参与轮换）与未实装因子不参与随机。

每次生成同时随机抽取一张合作地图（15 张）与一支埃蒙部队编制（19 支：
星灵 8、人类 6、异虫 5），作为本局的地图与敌方部队配置，与因子组合一同
展示在结果卡片中。

## 因子查询

「因子查询 <名称>」按名称（中/英文，全/半角标点均可）查询单个突变因子的
效果总结与详细说明，返回内容附因子图标。模糊命中多个因子时列出候选，
可继续发送「因子查询 <名称>」查看。数据来自「因子效果.xlsx」，共 68 个
因子：52 个常规因子（1～10 分）、10 个节日限定因子、6 个未实装因子。

## 定时推送

「订阅突变」后，机器人自动向订阅会话发送本周突变卡片（内容与「突变」
指令一致，含因子图标）；「退订突变」取消。默认每周一 08:00 推送，
推送日与时刻可配置（见下）。

- 订阅对象为发送指令的会话本身：群聊订阅到群，单聊/私聊订阅到个人；
  QQ 频道等场景暂不支持订阅。
- 订阅列表持久化在 localstore 的插件数据目录（`push_targets.json`），
  重启不丢失。
- 推送每个订阅会话每周至多一次：机器人在推送日该时刻之后启动时会补推
  一次本周的，其余时间不重复推送。
- 单个会话发送失败（如机器人被移出群）不影响其他订阅。
- **补发兜底**：主动消息被拒绝（见下）或机器人在推送时刻未开机时，
  本周突变会在该会话的下一条消息到来时随消息**被动回复**补发
  （尾注「（定时推送补发）」）。被动回复不需要「主动消息」权限，
  且内容按补发时的本周突变现算，不会过期；补发后本周内不再重复。

### 推送失败：主动消息无权限（code 40034105）

QQ 官方接口把「定时推送」这类**主动消息**（不回复用户消息）与被动回复
区别对待：机器人未开通主动消息权限时，发送群消息会被拒绝，返回
`code=40034105 主动消息失败, 无权限`。这不是插件故障——被动回复不受影响。

两种处理方式：

1. **开通主动消息**：到 [QQ 开放平台](https://q.qq.com) 为机器人申请/开通
   「主动消息」能力（具体入口以官方文档为准），之后定时推送即按配置时刻
   准点发送。
2. **不开通也能用**：依赖上面的补发兜底——本周突变随会话的下一条消息
   送达（QQ 官方机器人默认只接收 @ 机器人的消息，补发因此通常在有人
   @ 机器人说话时触发）。

「测试推送」的回复会直接给出失败原因与指引，无需翻日志。

### 线上定时测试

1. **立即验证发送**：在测试会话发送「订阅突变」，再发送「测试推送」——
   会立刻全量执行一次与定时任务相同的推送（不改动定时送达记录，可反复
   测试），并回报成功条数、失败原因与当前定时配置。
2. **验证定时触发**：在 `.env` 中把推送时刻临时改为当天的几分钟后
   （今天是周三就设 `TUBIAN_PUSH_WEEKDAY=2`），重启机器人等待触发：

   ```dotenv
   TUBIAN_PUSH_WEEKDAY=2
   TUBIAN_PUSH_HOUR=14
   TUBIAN_PUSH_MINUTE=30
   ```

   测试完成后删掉这三行即可恢复默认的每周一 08:00。

## 配置

数据目录默认为本模块（`nonebot_plugin_tubian/tubian`）下的 `突变列表数据` 文件夹，目录下需包含：

- `突变列表数据.xlsx` —— 突变数据表
- `因子效果.xlsx` —— 单因子效果表（因子查询）
- `因子图标/因子_<名称>.png` —— 因子图标
- `地图图标/<地图名>.png` —— 合作地图图片（15 张）

可在 `.env` 中通过 `TUBIAN_DATA_DIR` 修改数据目录：

```dotenv
TUBIAN_DATA_DIR=D:/path/to/突变列表数据
```

定时推送的推送日与时刻（默认周一 08:00）可用下列配置覆盖：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `TUBIAN_PUSH_WEEKDAY` | `0` | 推送星期：0=周一 … 6=周日 |
| `TUBIAN_PUSH_HOUR` | `8` | 推送时刻（小时，0～23） |
| `TUBIAN_PUSH_MINUTE` | `0` | 推送时刻（分钟，0～59） |

另外建议保留 `COMMAND_START=["", "/"]`，使指令支持有无 `/` 前缀两种写法。

## 测试

项目根目录下运行：

```bash
python -m unittest tests.test_tubian -v
```

测试覆盖数据加载、按时间选中（含周一换期边界与整轮循环折算）、序号/名称查询、
因子效果查询（名称归一化、模糊候选、卡片构造）、随机残酷组合生成
（因子分数、档位规律、参数解析）、消息卡片构造
（OneBot/QQ 图片段与纯文本降级）、定时推送
（订阅存储、目标提取、推送时机、发送分发、补发兜底）以及插件注册。

## 许可证

本插件仅供学习交流使用，突变数据来源于《星际争霸》中文维基。
